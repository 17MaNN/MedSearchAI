# AI Medical Search Assistant (RAG System)

## Overview

This project is an AI-powered Medical Search Assistant built using a Retrieval-Augmented Generation (RAG) architecture. It allows users to query medical information from custom documents such as PDFs and receive context-aware answers generated by a local language model.

The system combines semantic search with a vector database and a local LLM to provide accurate, grounded responses without relying on paid APIs.

---

## Features

* Semantic search using vector embeddings
* PDF ingestion and text chunking
* Vector storage using Endee
* Context-based retrieval
* Local LLM response generation using Ollama
* REST API using Flask
* Fully offline and free (no API costs)

---

## Tech Stack

* Python
* Flask
* Endee (Vector Database)
* Sentence Transformers (Embeddings)

## Architecture

User Query
↓
Embedding (Sentence Transformers)
↓
Endee (Vector Search)
↓
Context Retrieval
↓
Ollama (LLM)
↓
Final Answer

## Installation

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd <project-folder>
```

---

### 2. Create virtual environment

```bash
python -m venv venv
venv\Scripts\activate
```

---

### 3. Install dependencies

```bash
pip install flask endee sentence-transformers pymupdf ollama numpy
```

---

### 4. Install and run Ollama

Download and install Ollama from:
https://ollama.com

Run a model:

```bash
ollama run phi
```

---

## Usage

### Step 1: Ingest PDF Data

* Place your PDF file in the project directory
* Run your ingestion script to:

  * Extract text
  * Chunk content
  * Generate embeddings
  * Store in Endee

---

### Step 2: Run Flask API

```bash
python app.py
```

Server will start at:

http://127.0.0.1:5000

---

### Step 3: Query the API

Endpoint:
POST /ask

Request Body:

```json
{
  "query": "What is diabetes?"
}
```

Response:

```json
{
  "query": "What is diabetes?",
  "answer": "Diabetes is a chronic disease that affects blood sugar levels.",
  "context_used": [
    "Diabetes is a chronic disease...",
    "Hypertension is high blood pressure..."
  ]
}
```

## Key Concepts

### Retrieval-Augmented Generation (RAG)

Combines document retrieval with language models to generate grounded answers.

### Embeddings

Text is converted into vectors using Sentence Transformers for semantic similarity search.

### Vector Database

Endee stores embeddings and enables fast similarity-based retrieval.

### Local LLM

Ollama runs models locally, ensuring privacy and zero cost.

---

## Limitations

* Small models like phi may produce less accurate responses compared to larger models
* PDF extraction quality depends on document formatting
* No built-in ranking score from Endee
